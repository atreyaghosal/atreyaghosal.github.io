# Site documentation

How atreyaghosal.github.io is built, where things live, and how to make common
changes. Agent-specific rules are in [AGENTS.md](AGENTS.md).

## Overview

A static Jekyll site that GitHub Pages deploys from the `master` branch.
There's no Actions workflow. Pages builds the branch itself with the
`github-pages` gem (Jekyll 3.10, Ruby Sass 3.7.4, kramdown, Rouge). The
`Gemfile` depends on that same gem, so a local build matches the deploy.

The theme began as [contrast](https://github.com/niklasbuschmann/contrast) by
Niklas Buschmann (still the `upstream` remote) and has since been rewritten:
Material 3 colour roles, light and dark schemes with a header toggle,
self-hosted Roboto, and an accessibility pass.

## Running locally

Requires Ruby 3.x and Bundler.

```sh
bundle install              # installs into vendor/bundle, per .bundle/config
bundle exec jekyll serve    # http://localhost:4000, live rebuild
bundle exec jekyll build    # writes _site/
```

Changes to `_config.yml` aren't picked up by `serve`, so restart it after
editing the config.

## Layout of the repo

```
_config.yml          site settings, navigation tabs, footer links
_layouts/
  default.html       page shell: <head>, header, tabs, <main>, footer
  page.html          default + <h1>{title}
  post.html          default + title/date + "All posts" link
  cv_layout.html     same as page.html, kept separate for the CV
_includes/
  menu.html          tab row, built from site.navigation
  home.html          post cards, used on /blog/
  archive.html       dated list of all posts
  meta.html          post title + date
  social.html        footer links with Font Awesome icons
  theme-toggle.html  light/dark button and its script
  tok-toggle.html    "Symbols: Color / Muted / Off" toggle, illustrated posts only
  embed.html         responsive 16:9 iframe: {% include embed.html url="..." %}
_sass/
  index.sass         design tokens as Sass variables: type, layout, shape, colours
  tokens.sass        turns the colour variables into CSS custom properties, light and dark
  font.sass          @font-face for self-hosted Roboto / Roboto Mono
  basic.sass         element styles: typography, links, code, tables, figures
  layout.sass        app bar, tab row, reading column, footer
  classes.sass       components: buttons, cards, archive list, skip link, syntax colours
  illustrated.sass   "Papers Illustrated" toolkit (coloured tiles, arrows, callouts)
assets/
  css/index.sass         entry point → index.css (every page)
  css/illustrated.sass   entry point → illustrated.css (posts with illustrated: true)
  fonts/                 Roboto woff2 subsets
  fontawesome/icons.svg  icon sprite, generated by Liquid from the icons named in _config.yml
  katex/                 vendored KaTeX
  images/<post-slug>/    images, one folder per post
```

## Configuration (`_config.yml`)

- `title`, `description`: site name in the header and `<title>`. `description`
  is the footer text and may contain HTML.
- `intro`: the paragraph at the top of `/blog/`.
- `permalink: /:title/`: post URLs are the slug from the filename.
- `excerpt_separator: "\n\n\n"`: a post's excerpt ends at its first two blank
  lines in a row.
- `date_format`: date format on cards and post headers.
- `show_excerpts`: `true` shows cards on `/blog/`, `false` shows the plain archive list.
- `navigation`: the tab row. Each entry is `{file: "name.md"}` (title and URL
  come from that page) or `{title, url}`.
- `external`: footer links. `icon` is any Font Awesome 5 icon name (`github`,
  `envelope`, …).
- `comments`: Disqus or Isso hooks, currently off.
- `exclude`: files Jekyll skips, including the repo docs and `wiki/` (private
  notes, kept in the repo but not published). This replaces Jekyll's default list rather
  than adding to it, so the defaults (`Gemfile`, `vendor/bundle/`, …) are
  written out in full.

## Theme and styling

### Colour

Every colour is a Material 3 role. `_sass/index.sass` defines each role twice,
`$l-*` for light and `$d-*` for dark. `_sass/tokens.sass` publishes them as
custom properties (`--surface`, `--on-surface`, `--primary`,
`--outline-variant`, `--code-bg`, …), and rules use only `var(--…)`. To
recolour the site, edit the variables in `index.sass`.

### Light and dark

The dark scheme applies when:

1. the OS prefers dark **and** the reader hasn't chosen light, or
2. the reader chose dark with the header toggle.

The choice is stored in `localStorage.theme` and applied by a small script in
`<head>` before first paint, so the page doesn't flash the wrong scheme.
`theme-toggle.html` keeps the button state in step. `html[data-theme]` is the
switch every stylesheet keys off.

### Type and layout

Roboto at `calc(1rem + 0.15vw)` with line height 1.6, headings on the M3 type
scale in `rem`. Content sits in one column 45rem wide (`$measure`). Below 34rem
the tabs go full width and the padding tightens.

### Stylesheet caching

Stylesheet links carry `?v=<build timestamp>`, so a new deploy never pairs
fresh HTML with a stale cached stylesheet.

## Writing a post

1. Create `_posts/YYYY-MM-DD-my_slug.md`:

   ```yaml
   ---
   title:  "My Post Title"
   layout: post
   categories: misc
   mathjax: true        # optional: KaTeX
   illustrated: true    # optional: Papers Illustrated toolkit
   ---
   ```

2. Write the opening paragraph(s), then leave **two blank lines**. Everything
   above them becomes the excerpt on `/blog/`.
3. Put images in `assets/images/my_slug/` and reference them with
   `relative_url`. For large images, export a 1× and a 2× version and use
   `srcset`, as in `_posts/2025-08-20-unequal_voices.md`:

   ```html
   <figure>
     <img src="{{ "/assets/images/my_slug/fig-1440.png" | relative_url }}"
          srcset="{{ "/assets/images/my_slug/fig-720.png" | relative_url }} 720w,
                  {{ "/assets/images/my_slug/fig-1440.png" | relative_url }} 1440w"
          sizes="(max-width: 48rem) 100vw, 45rem"
          width="1440" height="643" alt="Describe what the image shows">
     <figcaption markdown="span">Caption with `markdown`.</figcaption>
   </figure>
   ```

   Always set `width`/`height` (prevents layout shift) and `alt`.

### Maths

With `mathjax: true` the post loads the vendored KaTeX and auto-render. Use
`$$...$$`. The setting is named `mathjax` for historical reasons, but
rendering is done by KaTeX.

### Papers Illustrated toolkit

With `illustrated: true` the post also loads `illustrated.css`, and the header
gains a Symbols toggle (Color / Muted / Off, stored in `localStorage.tokMode`).
Available classes, each in 11 colours (`red orange yellow green teal blue
babyblue purple pink cyan gray`):

| Class | Use |
| --- | --- |
| `hl hl-<c>` | coloured inline text |
| `tok tok-<c>` | coloured tile for a symbol, word or token |
| `tok tok-plain` | outlined tile for non-symbol diagram items |
| `arrow arrow-<c>` | coloured arrow between tiles (`&rarr;`, `&rArr;`, …) |
| `box box-<c>` | callout with a coloured left border |
| `tok-row` / `tok-row tok-row-top` | wrapping row of tiles, for diagrams |
| `tok-stack` + `tok-note` | tile with a small note under it |
| `tok-group` | keeps `f(x)`-style tile groups on one line |
| `caption` | italic centred caption under a diagram |

Inside raw HTML blocks write math as `\(...\)`. Inside Markdown paragraphs use
`$$...$$`, because kramdown strips the backslash from `\(`. The comment at the
top of `_posts/2026-09-23-papers_illustrated_found_in_translation.md` has a
full cheat sheet and that post's symbol-to-colour map.

## Other common changes

- **Add a tab**: create the page with `title` and `permalink` front matter, then
  add `{file: "page.md"}` to `navigation` in `_config.yml`.
- **Add a footer link**: append `{title, icon, url}` to `external`. The sprite
  `assets/fontawesome/icons.svg` builds itself from the icon names in
  `navigation` and `external`, using the data in `_data/font-awesome/icons.json`,
  so you don't edit it by hand.
- **Update publications**: they're listed on both the About page
  (`README.md`, Markdown list) and `cv.md` (HTML list). Update both.
- **Change the photo**: replace `assets/images/about/hike-{480,960}.jpg` and
  update `width`/`height`/`alt` in `README.md`.

## Deploying

Push to `master`. Pages builds and publishes within a minute or two. If it
fails, the error is in the repo's Actions tab under "pages build and
deployment". The first line is often Bundler noise, so scroll down for the
actual Jekyll or Sass error. Reproduce it locally with `bundle exec jekyll build`.

## Known issues

- Pagination markup exists in `home.html`, but `jekyll-paginate` isn't
  enabled, so `/blog/` lists every post.
- The Unequal Voices post body refers to the paper as "The Narrow Lens: LLM
  Bias and Queer Representation", while the title and publication list use
  "Unequal Voices".
